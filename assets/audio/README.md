# Sons (originaux)

Tous les fichiers `.mp3` de ce dossier ont été synthétisés pour ce jeu
(Python + ffmpeg, 22 050 Hz, mono). Aucun échantillon tiers, aucune
œuvre protégée. Licence : originaux du projet, libres d’utilisation
avec le jeu.
